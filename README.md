# Bank Marketing Data Mining

## Project Overview

This MSc Data Analytics project investigates bank marketing campaign data and the prediction of term-deposit subscriptions. The analysis was completed using **SAS Enterprise Miner**.

## Objectives

- Explore bank marketing campaign data.
- Prepare data for modelling and analysis.
- Examine feature selection and missing-data imputation approaches.
- Compare predictive models using appropriate evaluation measures.

## Methods and Tools

- SAS Enterprise Miner
- Data preparation and exploration
- Feature selection
- Missing-data imputation
- Predictive modelling and model evaluation

## Key Findings

The project compared predictive modelling approaches and data preparation strategies. The regression model using the default imputation approach performed strongest among the evaluated alternatives in the reported analysis.
